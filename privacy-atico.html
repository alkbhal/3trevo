Política de Privacidade

Ático — Inteligência Financeira · Última atualização: maio de 2026

Resumo: O Ático armazena todos os seus dados financeiros exclusivamente no seu dispositivo. Nenhuma informação pessoal ou financeira é transmitida, compartilhada ou vendida.

2. Quais dados o aplicativo coleta?

O Ático não coleta dados pessoais identificáveis. Todos os dados financeiros que você insere (lançamentos, dívidas, cartões, metas) são armazenados localmente no seu dispositivo, utilizando banco de dados local (Hive).

  • Dados financeiros: armazenados somente no dispositivo
  • Preferências do usuário: armazenadas somente no dispositivo
  • Nenhum dado é enviado a servidores externos
  • Nenhum dado é compartilhado com terceiros

3. Permissões do aplicativo

  • INTERNET: Utilizada apenas para verificar atualizações do aplicativo e exibir conteúdo educativo. Nenhum dado financeiro é enviado.

4. Retenção de dados

Todos os dados permanecem no seu dispositivo enquanto o aplicativo estiver instalado. Ao desinstalar o aplicativo, todos os dados locais são removidos.

5. Crianças

O Ático é destinado a usuários com 18 anos ou mais. Não coletamos intencionalmente dados de menores de 13 anos.

6. Alterações nesta política

Qualquer alteração será publicada nesta página com a data de atualização. O uso contínuo do aplicativo após alterações constitui aceite da política vigente.
